# 学习计划

## 学习者信息
- 水平: 初级开发者（1-2年经验）
- 目标: 全面系统学习，建立从操作系统到云原生的完整知识体系

## 学习路径

### 阶段一：操作系统（5次学习）

理解计算机最底层的运作机制。

- [ ] 1.1 从纸带到操作系统 — 计算机诞生、冯诺依曼架构、中断机制
- [ ] 1.2 现代操作系统的雏形 — 内核态/用户态、系统调用
- [ ] 1.3 Linux文件系统 — "一切皆文件"、inode、ext
- [ ] 1.4 Linux内存管理 — 虚拟内存、页表、内存分配
- [ ] 1.5 Linux进程管理 — 进程模型、调度、IPC

### 阶段二：后端语言 - Java/Python 基本概念与原理（4次学习）

理解你每天写的代码底下发生了什么。

- [ ] 2.1 高级语言的演进之路 — 汇编→C→Java，编译/解释、JVM、JIT
- [ ] 2.2 面向对象 — OOP设计、封装/继承/多态的实现
- [ ] 2.3 内存管理 — 堆栈模型、GC算法、引用类型
- [ ] 2.4 线程并发 — 线程模型、锁、CAS、并发工具

### 阶段三：中间件（3次学习）

后端系统的核心基础设施。

- [ ] 3.1 数据库 & 缓存 — 关系型DB、Redis、一致性问题 *(仓库待补充)*
- [ ] 3.2 消息队列 — 异步解耦、削峰、常见MQ对比 *(仓库待补充)*
- [ ] 3.3 可观测性 — 日志、指标、链路追踪 *(扩展话题)*

### 阶段四：分布式系统（1次学习）

从单机到集群的思维跃迁。

- [ ] 3.4 分布式系统 — CAP定理、RPC框架、服务发现、负载均衡、Raft共识、高可用

### 阶段五：容器技术（1次学习）

理解容器化的本质。

- [ ] 4.1 从虚拟化到容器 — Hypervisor、cgroups、namespace、Docker原理与使用

### 阶段六：Kubernetes（3次学习）

了解K8s基本概念和设计原理。

- [ ] 4.3 Kubernetes基础概念 — Pod、Service、Deployment、声明式API
- [ ] 4.4 Kubernetes实现分析 — etcd、API Server、Scheduler、Controller
- [ ] 4.5 Kubernetes运行机制 — kubelet、CRI、CNI、CSI

## 备注

- 阶段六以"了解概念和原理"为目标，不追求深入实现细节
- ch4/02（云计算的混沌时代）作为背景阅读材料，不单独作为学习节点
