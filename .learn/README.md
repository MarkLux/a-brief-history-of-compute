# .learn 目录说明

此目录用于存储学习进度和计划，由 AGENTS.md 定义的交互式学习系统使用。

## 文件说明

| 文件 | 用途 |
|------|------|
| `progress.json` | 学习进度数据（知识点完成状态、学习者信息） |
| `plan.md` | 个性化学习计划（学习路径、阶段划分） |
| `README.md` | 本文件 |

## 注意事项

- `progress.json` 会在学习过程中自动更新
- 如需重置进度，可删除 `progress.json` 或使用 `重置` 指令
- `plan.md` 在首次学习时自动生成，后续可手动修改
